# Half Adder

Verilog implementation of a Half Adder using basic combinational logic.

## Inputs
- A
- B

## Outputs
- Sum
- Carry

## Logic
- Sum = A XOR B
- Carry = A AND B

## Files
- `half_adder.v` → Design module
- `half_adder_tb.v` → Testbench

## Tools Used
- Verilog HDL
- Vivado
- Spartan-7 FPGA
