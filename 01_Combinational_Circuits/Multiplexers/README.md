# Multiplexers

This folder contains Verilog implementations of multiplexers.

## Included
- 2:1 Multiplexer
- 4:1 Multiplexer

# 2x1 Multiplexer

Verilog implementation of a 2-to-1 Multiplexer.

## Function
Selects one of two input signals based on the select line.

## Files
- `mux2to1.v`
- `mux2to1_tb.v`

## Tools Used
- Verilog HDL
- Vivado
- Spartan-7 FPGA

# 4x1 Multiplexer

Verilog implementation of a 4-to-1 Multiplexer.

## Function
Selects one of four input signals based on select lines.

## Files
- `mux4to1.v`
- `mux4to1_tb.v`

## Tools Used
- Verilog HDL
- Vivado
- Spartan-7 FPGA
