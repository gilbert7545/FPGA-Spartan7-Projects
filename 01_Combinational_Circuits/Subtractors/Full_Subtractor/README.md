# Full Subtractor

Verilog implementations of Full Subtractor circuits.

## Included Designs

### Basic Full Subtractor
Performs binary subtraction with borrow input.

### Full Subtractor using Half Subtractor
Hierarchical implementation using Half Subtractor modules.

> Note: This design requires the `half_subtractor.v` module from the Half_Subtractor section.

## Files
- `full_subtractor.v`
- `full_subtractor_tb.v`
- `full_subtractor_using_half_subtractor.v`
- `full_subtractor_using_half_subtractor_tb.v`

## Tools Used
- Verilog HDL
- Vivado
- Spartan-7 FPGA
