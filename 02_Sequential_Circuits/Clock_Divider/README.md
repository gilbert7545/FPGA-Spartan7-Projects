# Clock Divider

Clock divider implementation for reducing FPGA clock frequency.

## Purpose
Spartan-7 FPGA boards typically provide a high-frequency clock source (100 MHz).  
This module divides the clock frequency for slower operations and timing control.

## Files
- `clock_divider_top.v`

## Tools Used
- Verilog HDL
- Vivado
- Spartan-7 FPGA
